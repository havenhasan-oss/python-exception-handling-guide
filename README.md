# Python Exception Handling Guide

## 🚀 Overview

A well-structured Python project demonstrating professional exception handling techniques with practical examples.

## 📌 Features

* Handling common exceptions (`ValueError`, `IndexError`)
* Using `try`, `except`, `else`, and `finally`
* Managing multiple exceptions
* Resource cleanup using `with` statement
* Raising custom exceptions
* Performance comparison using `timeit`

## 📂 Project Structure

```
main.py
examples/
```

## ▶️ How to Run

```bash
python main.py
```

## 📖 Examples

Each file inside the `examples` folder demonstrates a specific concept of exception handling.

This project is created for learning and practicing Python exception handling.
